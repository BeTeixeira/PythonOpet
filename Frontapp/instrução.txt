# GameStar — front-end (React Native / Expo)

Front-end das 4 telas do app, implementado com **Expo Router** (navegação por
arquivos). Sem back-end — todo o conteúdo vem de arquivos de dados locais em
`src/data/`, fáceis de editar ou trocar por uma API depois.

## Como rodar

```bash
npm install
npx expo install   # ajusta as versões das libs à versão do Expo SDK
npx expo start
```

Abra no celular com o app **Expo Go** (escaneando o QR code) ou pressione
`w` no terminal para abrir no navegador.

## Estrutura de pastas

```
app/                    ← cada arquivo aqui é uma TELA (rota)
  _layout.tsx            layout raiz (tema + navegação em pilha)
  index.tsx               Catálogo / Home        → rota "/"
  biblioteca.tsx           Minha lista (filtros)   → rota "/biblioteca"
  amigos.tsx               Lista de amigos         → rota "/amigos"
  jogo/[id].tsx            Detalhe do jogo         → rota "/jogo/1", "/jogo/2"...

src/
  theme/
    colors.ts             paleta de cores (light/dark)
    ThemeContext.tsx       lógica do toggle claro/escuro
  data/
    games.ts               dados dos jogos (textos, notas, imagens)
    friends.ts              dados dos amigos
  components/
    TopBar.tsx              barra superior com os ícones de navegação
    GameCard.tsx             card de jogo (catálogo e minha lista)
    FriendCard.tsx           card de amigo
    FilterPills.tsx          chips de filtro (usado na Minha lista)
    StarRating.tsx           estrelas de avaliação
```

## Onde editar cada coisa

| Quero mudar...                              | Arquivo                                  |
| -------------------------------------------- | ----------------------------------------- |
| Nome, gênero, sinopse, notas dos jogos       | `src/data/games.ts`                       |
| Comentários de um jogo                       | `src/data/games.ts` (campo `comments`)    |
| Nome/info dos amigos                         | `src/data/friends.ts`                     |
| Imagem de um jogo/amigo                      | campo `image`/`avatar` — instruções no topo de `src/data/games.ts` e `friends.ts` |
| Ícones (Ionicons)                            | qualquer `<Ionicons name="..." />` — trocar o `name` já troca o ícone. Lista completa: https://icons.expo.fyi |
| Cores do app (claro/escuro)                  | `src/theme/colors.ts`                     |
| Texto fixo de tela (títulos, placeholders)   | procure o comentário `// TEXTO EDITÁVEL` no arquivo da tela em `app/` |
| Filtros da tela "Minha lista"                | array `FILTERS` no topo de `app/biblioteca.tsx` |

## Como adicionar navegação entre telas

O Expo Router usa **roteamento por arquivo**: o caminho do arquivo dentro de
`app/` já é a URL da tela. Não existe um arquivo central de rotas.

1. **Criar uma tela nova**: crie `app/nome-da-tela.tsx` — ela já vira a rota
   `/nome-da-tela` automaticamente.
2. **Navegar até ela**: em qualquer componente, use:
   ```tsx
   import { useRouter } from "expo-router";
   const router = useRouter();
   router.push("/nome-da-tela");
   ```
   (é exatamente assim que o `TopBar.tsx` e o `GameCard.tsx` navegam hoje —
   use esses dois arquivos como referência).
3. **Telas com parâmetro** (como o detalhe do jogo): nomeie o arquivo com
   colchetes, ex. `app/jogo/[id].tsx`, navegue com
   `router.push(\`/jogo/${id}\`)`, e leia o parâmetro dentro da tela com
   `useLocalSearchParams()` (já usado em `app/jogo/[id].tsx`).
4. Se preferir um link declarativo em vez de botão, pode usar
   `<Link href="/nome-da-tela">texto</Link>` importado de `expo-router`.
