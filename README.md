## 📖 Visão Geral

Este projeto consiste em uma aplicação desenvolvida em **Python** projetada para rodar de forma escalável em ambiente Cloud. O foco do desenvolvimento está no foco em futuras requisições e a adição de novos componentes.

<details>
<summary><strong>🎯 Ideia principal (Clique para expandir)</strong></summary>
<br>
Nosso projeto consiste na criação de um app para organizar uma lista de jogos populares, a partir de um CRUD, aonde poderemos adicionar jogos e avaliá-los com uma nota de 1 a 5 
</details>


## 🛠️ Stack Tecnológica e Princípios

* **Linguagem Core:** Python 3.x
* **Padrões de Projeto:** Foco em **Clean Code** e **SOLID**, garantindo componentes reusáveis e código sustentável.
* **Infraestrutura:** Preparado para deploy em nuvem (substitua por AWS, GCP, Azure, etc.).
* **Isolamento:** Uso de ambientes virtuais (`venv`) / Docker.
